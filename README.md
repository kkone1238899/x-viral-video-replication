- 什么时候用 / 常见坑：边界条目——真人 UGC 组织与产能方法，不是 AI 视频反推提示词；与库内同作者“UGC 逆向三要素”条目角度不同（彼为单条拆解，此为放量顺序），不重复。

**适用场景**：做 UGC 矩阵、App 获客视频放量的团队与品牌方。

**怎么用它搞钱**：用赢家格式加标准化流程做 UGC 代运营，按条或按月收费。
